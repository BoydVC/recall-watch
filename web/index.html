    About Recall Watch

    Recall Watch is a TokenMax local utility: keep a household register of cars, car seats, kids’ gear, and appliances, then flag possible matches against public NHTSA and CPSC recall APIs.

    • Never invents recall facts — only API results or clearly labeled DEMO placeholders.
    • Seed items are generic SAMPLE entries (no real VINs/serials). Edit them in Register.
    • Edits stay in localStorage on this device.
    • Live snapshot is baked at build time (data/recalls.json). Offline single file: dist/recall-watch.html.

    Official sources

    • NHTSA Recalls · API api.nhtsa.gov/recalls/recallsByVehicle
    • CPSC Recalls · API saferproducts.gov/RestWebServices/Recall
